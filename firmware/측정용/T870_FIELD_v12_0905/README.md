# T870_FIELD_v12_0905

현장 시험 도구. `mcu_ws` 저장소의 `T870_FIELD_v9_0904` 기반.

## 근거가 되는 실측값 (0904, v9 에서 그대로 가져옴)

```
조향 중앙 ADC     355
1도당 ADC 카운트   14.5
최대 조향각        ±22도  (ADC 36 ~ 674)
하드리밋           25 ~ 700
조향 방향          ADC 가 커지면 좌회전
애커만             좌회전 시 오른쪽 23도 / 왼쪽 21도 (차종 특성, 측정오차 아님)
엔코더 디바운스    200 us   ← counts_per_meter 와 한 쌍. 바꾸지 말 것
```

## v9 → v12 변경

| 버전 | 내용 |
|---|---|
| v10 | E-Stop 추가 (하드웨어 D24 + 소프트), 5초 주행 시험, ADC 카운트 단위 미세 이동 |
| v11 | 구동을 5 PWM 단위 증감으로, ROS 규약(+ = 우측) 각도 병기 |
| v12 | `J` = 기준 중앙 355 복귀, 구동을 w/b/e 로 일원화, 도움말 정리 |

**v9 의 실측값·핀·하드리밋은 하나도 건드리지 않았다.**

## 조작

### 조향 — 전부 ADC 폐루프. ms 로 미는 코드는 없다

| 키 | 동작 |
|---|---|
| `G<n>` | ADC n 으로 이동 (예: `G400`) |
| `C` | 기록된 중앙으로 (`K` 로 기록한 값) |
| `J` | **기준 중앙 355 로** (`K` 와 무관. 되돌리기용) |
| `L1`~`L22` | 왼쪽 n도 (ADC 증가) |
| `R1`~`R22` | 오른쪽 n도 (ADC 감소) |
| `,` / `.` | 좌 / 우 **1 카운트** (약 0.07도) |
| `<` / `>` | 좌 / 우 **5 카운트** |
| `[` / `]` | 좌 / 우 **10 카운트** |
| `a` / `d` | 좌 / 우 N 카운트 (`N<n>` 으로 폭 변경) |
| `K` | 지금 위치를 중앙으로 기록 |
| `I` | 조향 모터 방향 반전 |

### 구동 — 램프 없음. 누르는 즉시 인가

| 키 | 동작 |
|---|---|
| `w` | 전진 PWM **+5** |
| `b` | 후진 PWM **+5** |
| `e` | 지금 방향 PWM **−5** (0 이면 정지) |

상한 255. **방향을 바꾸면 0 부터 다시 올라간다** (역토크 보호).

### 주행 시험 — 엔코더 자동 측정

| 키 | 동작 |
|---|---|
| `1` | 10초 주행 (PWM 50) |
| `2` | 5초 주행 (PWM 50) |
| `o` | 엔코더 카운터만 리셋 |
| `M<n>` | n미터 갔다 → counts_per_meter (예: `M4.85`) |

`1`/`2` 는 카운터를 자동으로 리셋하고, 주행 후 코스팅 3초까지 세서 결과를 낸다.

### 정지 · 안전

| 키 | 동작 |
|---|---|
| `0` / `x` / 스페이스 | 즉시 정지 |
| `!` | E-Stop 걸기 (래치) |
| `~` | E-Stop 래치 해제 |

하드웨어 E-Stop(D24, NC 접점)은 항상 감시한다. 단선도 정지로 처리된다.
래치가 걸리면 조향·구동·주행시험이 전부 거부된다.

|---|---|
| `S` | 현재 전체 상태 |
| `h` | 도움말 |

## 부호 규약 — 헷갈리기 쉬운 부분

**이 차는 ADC 가 커지면 좌회전이다. ROS 토픽은 + 가 우측이다. 정반대다.**

```
deg_ros = (355 - ADC) / 14.5        ← + 가 우측
```

| ADC | ROS 각도 |
|---|---|
| 36 | +22.0도 (우) |
| 355 | 0.0도 (중앙) |
| 674 | −22.0도 (좌) |

`S` 출력의 `조향각(ROS +우)` 이 ROS 와 같은 부호다.
나중에 v38 에 넣을 때 ROS 에서 `+10`(우측 10도)이 오면 목표 ADC 는
`355 − 10 × 14.5 = 210` 이다.

## 측정 순서

```

,  .  < >   미세 이동으로 실제 직진 중앙 찾기

o

            줄자로 실제 거리 측정

```
