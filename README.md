# T870 MCU

자율주행 차량 T870 의 저수준 제어. **아두이노 시리얼 브릿지 + 명령 중재기**를 한 ROS 2 패키지에 담았습니다.

**처음이면 [`시작하기.md`](시작하기.md) 부터 보세요.**

---

## 구조

```
카메라 ─┐
라이다 ─┼→ /..._drive, /..._wheel, /..._stop ─→ [중재기] ─→ /mcu/cmd_* ─→ [브릿지] ─→ 아두이노
GPS   ─┘                                          ↑
                                          /drive_mode (구간 0~11)
```

- **브릿지** `bridge_node.py` — 시리얼 송수신, 오도메트리, TF, E-Stop 래치
- **중재기** `manager_node.py` — 어느 팀 명령을 쓸지 구간별로 결정

두 노드는 같은 패키지(`t870_mcu`)에 있습니다. 별도 설치 없습니다.

---

## 빠른 실행

```bash
cd ~/mcu_ws && ./실행.sh
```
인자 없이 치면 무엇을 할 수 있는지 목록이 나옵니다. **창 하나에 하나씩** 띄웁니다.

| 명령 | 하는 일 |
|---|---|
| `./실행.sh 브릿지` | 아두이노 연결 |
| `./실행.sh 중재` | 명령 중재기 |
| `./실행.sh 조종` | WASD 수동 운전 (별도 창) |
| `./실행.sh 프레임` | 센서 위치 TF |
| `./실행.sh 전체` | 브릿지+중재를 한 창에 |
| `./실행.sh 점검` | 안 될 때 제일 먼저 |
| `./실행.sh 상태` | 지금 뭐가 도는지 |

## 개발

시험 (차 없이 돌아갑니다):
```bash
cd ~/mcu_ws/src/t870_mcu && PYTHONPATH=. python3 -m pytest test/ -q
```

설정↔코드 정합성 감사:
```bash
cd ~/mcu_ws && python3 tools/audit.py .
```

펌웨어는 `firmware/T870_MCU_v37.ino` (아두이노 IDE 로 굽습니다. MCU 담당만).
